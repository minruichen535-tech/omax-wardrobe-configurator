# 璞舍首篇素材与证据清单

## 先看设计准入

| 页码 | 当前可做什么 | 发布定稿前的阻塞项 | 当前状态 |
|---:|---|---|---|
| 1 | 可先做版式与标题 | 真实完工主图、场景性质、Logo规范 | 条件可设计 |
| 2 | 可做三格信息结构 | 基础开放型照片、组件平铺；若用用户价格需脚注 | 条件可设计 |
| 3 | 只能做线框 | 璞舍真实BOM、服务包含项、产品拆解源文件 | **未满足前不可正式设计** |
| 4 | 只能做三列版式 | 三种配置定义、对应照片和包含项 | **未满足前不可正式设计** |

## P0：正式设计前必须拿到

### 1. 品牌与视觉基础

- [ ] PURENEST / 璞舍标准 Logo：SVG、透明 PNG、深浅底版本
- [ ] 品牌标准中文名、英文名与是否必须同时出现
- [ ] 现有品牌色、禁用色、字体授权与商业使用范围
- [ ] 产品图片可使用范围：客户家、展厅、样板间、渲染图分别怎样标注
- [ ] 图片版权与客户授权确认

### 2. 至少一套真实主视觉

- [ ] 一套已完工金属衣柜/衣帽间的竖构图高清图
- [ ] 同空间正视、45度、局部、开启状态各一张
- [ ] 能看见金属架体与门/侧板/功能件关系
- [ ] 原始分辨率建议不低于 3000 px 长边
- [ ] 场景信息：客户家/展厅/样板间、城市、完成时间
- [ ] 拍摄时清除客户照片、地址、儿童信息和其他隐私

### 3. 真实 BOM 一级清单

需由产品、报价和交付团队共同确认，不由内容团队自行补齐。

- [ ] 金属主体：立柱、横轨/挂轨、挂杆、层架等准确名称
- [ ] 层板：是否提供、材质类别、规格名称
- [ ] 内部功能件：抽屉、裤架、拉篮、收纳篮等
- [ ] 灯光：是否提供、控制方式、是否含电工施工
- [ ] 柜门系统：门型、门框、轨道、铰链/五金
- [ ] 侧顶收口：侧板、顶封、踢脚或其他收口
- [ ] 安装辅材：仅列实际会进入报价或合同的项目
- [ ] 服务项目：测量、设计、运输、上楼、安装、拆旧、补墙、售后
- [ ] 每个项目标注“标配 / 选配 / 第三方 / 不提供”

### 4. 报价与交付口径

- [ ] 璞舍目前实际使用的计价单位
- [ ] 计价单位的公式与适用范围
- [ ] 报价是否含税
- [ ] 运输、上楼、安装的包含范围和服务城市
- [ ] 异形、非标、远程、复杂墙体怎样确认，不必在首篇公布金额，但必须能确认是否为独立项目
- [ ] 售后范围、期限、责任主体
- [ ] 一份真实脱敏报价单用于内部核对
- [ ] 下一篇是否确实能公开一份脱敏报价单

## P1：逐页照片清单

### 第1页｜封面

**必须有**

- [ ] 真实完工主图 1 张，产品位于右侧或可裁切到右侧
- [ ] 画面中至少可识别一处金属主体
- [ ] 产品与门/侧板关系清楚

**有则更好**

- [ ] 同空间关闭门与开启门两种状态
- [ ] 生活物品已整理但不过度空置的真实状态

**没有时删除/弱化**

- 没有客户授权：改用展厅图并明确“展厅实拍”。
- 只有渲染图：不得使用“真实交付”“真实家庭”。

### 第2页｜便宜印象来源

**必须有**

- [ ] 基础开放型实拍
- [ ] 组件白底平铺或统一线稿
- [ ] 完整带门方案轮廓/实拍，用于说明完整程度不同

**有则更好**

- [ ] 同一空间逐步增加配置的三阶段照片

**没有时删除/弱化**

- 无同系列素材：使用中性线稿，不拼贴三个不同风格项目。
- 无璞舍低价方案：不得出现璞舍价格。

### 第3页｜完整交付拆解

**必须有**

- [ ] 与 BOM 一一对应的产品正视图或三维源文件
- [ ] 架体、功能件、门/收口、服务四层拆解
- [ ] 所有部件准确名称

**有则更好**

- [ ] 每个核心组件的白底照片
- [ ] 门框、轨道、侧顶收口节点特写

**没有时删除/弱化**

- BOM 未确认：整页不得进入精稿。
- 璞舍不提供的服务：不进入“完整交付”图，只在正文提醒用户向供应方确认。

### 第4页｜三种配置

**必须有**

- [ ] 三种“交付完整度”的内部定义
- [ ] 每种对应 3—5 个真实包含项
- [ ] 同尺度图片或统一三维模型

**有则更好**

- [ ] 同一空间的三套方案
- [ ] 同一系列的开放、完整、带门案例

**没有时删除/弱化**

- 无稳定三档产品：文案改为“报价时常见的三种完整程度”，不得称“璞舍三大系列”。
- 无带门业务：删除“带门高配型”，按真实业务重新分类。

### 第5页｜公平比价清单

**必须有**

- [ ] 计价单位说明
- [ ] 产品、功能件、门、安装运输、售后的边界
- [ ] 一份真实报价单用于内部核对六项清单

**有则更好**

- [ ] 同空间两个方案的内部对照，不要求公开金额
- [ ] 合同包含项的脱敏截取

**没有时删除/弱化**

- 未确认服务范围：表格写“是否包含？请确认”，不要预填勾选。

### 第6页｜预算更容易控制

**必须有**

- [ ] 标准尺寸或标准模块范围
- [ ] 基础配置定义
- [ ] 少异形、少收口、安装条件明确的业务事实依据
- [ ] 对应真实照片

**有则更好**

- [ ] 标准与非标项目数量对照
- [ ] 内部工时或物料验证

**没有时删除/弱化**

- 无标准化边界：删除“标准尺寸更容易控制预算”。
- 无布帘产品或配套：删除“布帘”，改为“简单遮挡方案”或完全不提。

### 第7页｜总价增加项

**必须有**

- [ ] 柜门、功能件、灯光、侧顶收口、异形、复杂安装六类是否真实存在
- [ ] 每类项目至少一张真实节点图
- [ ] 哪些由璞舍交付、哪些需第三方配合

**有则更好**

- [ ] 同空间基础版与增加项目版的 BOM 对照
- [ ] 门开启与抽屉/裤架避让图

**没有时删除/弱化**

- 无同口径价格：不写任何增加金额或倍数。
- 无门系统：不说“柜门是最大成本”，只说“门可能成为重要成本项”。

### 第8页｜品牌立场与预告

**必须有**

- [ ] 内部确认的价格表达原则
- [ ] 五项检查标签：尺寸、门、内部配置、交付、售后
- [ ] 下篇是否有真实报价单的明确答复

**有则更好**

- [ ] 已获授权的报价单局部
- [ ] 下篇选定的真实空间照片

**没有时删除/弱化**

- 无报价单：将“下一篇拆真实报价”改为“下一篇继续拆报价构成”。

## P1：需要产品/报价团队书面确认的问题

1. “完整衣柜”在璞舍合同中具体包括哪些项目？
2. 柜门、门框、轨道与五金是否由璞舍统一交付和保修？
3. 层板、侧板、顶封、抽屉的材质与供应责任是什么？
4. 璞舍是否存在公开可用的标准尺寸或标准模块？
5. 哪些情况需要非标设计或第三方施工？
6. 测量、设计、运输、上楼、安装是否包含在报价内？
7. 哪些城市或距离范围可提供安装？
8. 拆旧、墙面修补、电工、灯带开槽分别由谁负责？
9. 报价有效期、税费和售后范围怎样写？
10. 是否允许公开一份真实脱敏报价单？

## 不需要为首篇准备的资料

以下内容不在首篇目标内，避免延误制作或诱发跑题：

- 金属残值、回收渠道与回收价
- 搬家拆装案例
- 长期寿命、变形年限
- 防尘对照实验
- 承重测试完整专题
- “什么人更适合木柜/金属柜”的人格或家庭画像

若现有资料中出现这些内容，本篇不使用，保留给后续专题。
